<h2><em>the notes between the notes...</em></h2>
<br>
This is a microtonal MIDI keyboard, made for the Hack Club Half-Life project week 3/8.
<br>
This keyboard adds extra keys for the keys C &#119090;, C 3/2#, D &#119090;, D 3/2#, and so on. This keyboard uses low-profile MX keys as its switches, which are set in a matrix as to save IO on the Waveshare ESP32-S3-Zero. There is also a rotary encoder present on the board for volume control and mute functions. Special keycaps for this board will be 3D-Printable and found in the Keycaps folder in this repository once created.
